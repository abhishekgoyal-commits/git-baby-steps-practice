# Simple Python Calculator

This small project demonstrates a minimal Python calculator with basic arithmetic functions:

- `add(a, b)` — returns the sum of two numbers
- `subtract(a, b)` — returns the difference (a - b)
- `multiply(a, b)` — returns the product of two numbers

## Example

```python
from calculator import multiply

result = multiply(4, 5)
print(result)  # 20
```

## Usage

Run the CLI program:

```bash
python work/module03-task/main.py
```

The program will prompt for two numbers and an operator. Use `*` to multiply.
